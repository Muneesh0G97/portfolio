Nikhil - Data Analyst Portfolio (plain HTML / CSS / JS)

Files
  index.html  - all content and sections (edit text here)
  style.css   - colors, fonts, spacing (edit :root variables at the top)
  script.js   - nav, scroll animation, query form (set MY_EMAIL here)
  resume.pdf  - ADD THIS FILE yourself; the Download Resume buttons point to it

To edit:
  1. Text/content  -> index.html
  2. Colors/theme  -> style.css, the :root { } block
  3. Your email    -> script.js, MY_EMAIL = "you@example.com"
  4. GitHub/LinkedIn -> search index.html for href="#" in the Contact and Footer sections
  5. Resume        -> drop your PDF next to index.html and name it resume.pdf

To view: just double-click index.html (no build step, no server needed).
